# Group Edit (minimum)

## Where

Teacher → open Study Group → Group Dashboard → **Edit** (pencil top-right, or “Edit group” button).

## What you can change

| Field | Editable |
|-------|----------|
| Group name | Yes |
| Subject | Yes |
| Class / Exam / Language | Yes (optional) |
| Free joins: Auto / Approve | Yes |
| Invite code / link | **No** (links stay valid) |

## Test

1. Hot restart (`R`)
2. Teacher Dashboard → group → Edit
3. Change name → Save
4. Title updates; invite code same

## Manual setup

None — no SQL, no `.env`.
